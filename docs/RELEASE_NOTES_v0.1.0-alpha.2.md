# Wizardry VI Korean v0.1.0-alpha.2

두 번째 공개 알파 빌드입니다. 실제 DOSBox 플레이 테스트로 확인된 런타임 회귀를 수정했습니다.

## 주요 수정

- 한국어 글자 뒤 검은 사각형이 생기던 메뉴 배경 렌더링 문제 수정
- 구성원 추가 후 `WROOT`가 재시작되며 게임 진행이 막히던 문제 수정
- 초상화 선택, 캐릭터 확인/상태, 이름 변경 화면에서 DOS 종료 트랩으로 빠지던 문제 수정
- 긴 캐릭터 명단(`WPCMK.OVR`)의 성별/종족/직업이 깨져 보이던 문제 수정
- 성별/종족/직업의 compact 표시를 한국어 2글자 단위로 정리해 2바이트 글리프 쌍이 잘리지 않도록 수정

## 번역 범위

- MSG 원문 5,161개 구조 검증
- 번역 CSV 4,720행 적용
- 실제 변경 메시지 4,492개
- 아이템 이름 452개
- 몬스터 레코드 186개
- NPC 이름 30개
- 한국어 인트로 로고 포함

## 설치

기존 Wizardry VI GOG DOS판 게임 폴더를 백업한 뒤 릴리스 ZIP의 파일을 게임 폴더에 덮어쓰면 됩니다. 저장 파일은 포함하거나 변경하지 않습니다.

## 런타임 기준

`Runtime Recovery Test8`에서 다음을 실제 플레이로 확인했습니다.

- 캐릭터 관련 메뉴 진입 시 강제 종료 없음
- 긴 캐릭터 명단의 한국어 성별/종족/직업 정상 출력
- Test1에서 확인한 검은 배경 및 구성원 추가 재시작 수정 유지
